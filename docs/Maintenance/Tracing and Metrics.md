# Logs Configuration

AI Core uses [.NET `ILogger`](https://learn.microsoft.com/en-us/dotnet/core/extensions/logging) for application logging. Logging settings can be configured via `appsettings.json`, environment variables, or through the AI Core Monitoring API.

---

## Configure Logging via `appsettings.json` or Environment Variables

Logging is typically configured in the `Logging` section of `appsettings.{ENVIRONMENT}.json`, where `{ENVIRONMENT}` corresponds to your runtime environment (e.g., `Development`, `Production`).

Below is an example configuration commonly generated by the ASP.NET Core web app templates:

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  }
}
```

For more details on configuring logging in ASP.NET Core, refer to:
- [Configure logging](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/logging/?view=aspnetcore-9.0#configure-logging)
- [Set log level using command line, environment variables, or other configuration sources](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/logging/?view=aspnetcore-9.0#set-log-level-by-command-line-environment-variables-and-other-configuration)

---

## Configure Logging via AI Core Monitoring API

> ⚠️ **Note**: The Monitoring API supports only a **global log level per category** that applies to all enabled logging providers.  
> For fine-grained configuration (e.g., different levels per provider), use environment variables or `appsettings.json`.

### 📥 Get Logging Configuration

**Request:**
```http
GET https://{HOST}/api/v1/monitoring
```

**Response:**
```json
{
  "openTelemetrySettings": [],
  "logLevelSettings": [
    {
      "category": "AiCoreApi.SemanticKernel.Agents.*",
      "logLevel": "Information"
    },
    {
      "category": "Microsoft.AspNetCore",
      "logLevel": "Warning"
    }
  ]
}
```

---

### 📤 Set Logging Configuration

**Request:**
```http
POST https://{HOST}/api/v1/monitoring
```

**Payload:**
```json
{
  "openTelemetrySettings": [],
  "logLevelSettings": [
    {
      "category": "AiCoreApi.SemanticKernel.Agents.*",
      "logLevel": "Information"
    },
    {
      "category": "Microsoft.AspNetCore",
      "logLevel": "Warning"
    }
  ]
}
```

# OpenTelemetry Configuration
AI Core supports [OpenTelemetry-based](https://opentelemetry.io/) instrumentation for monitoring, tracing, and exporting telemetry data. Configuration can be done via:

- **Environment variables** (prefixed with `MONITORING_`)
- **`appsettings.json`** (under the `Monitoring` section)
- **AI Core Monitoring API**  
  Endpoint: `https://{HOST}/api/v1/monitoring`

Below is the full list of supported OpenTelemetry-related settings.

---

## Instrumentation Settings

| Setting Name | Environment Variable | appsettings.json Key | Description | Example Value |
|--------------|----------------------|------------------------|-------------|----------------|
| `EnableOpenTelemetry` | `MONITORING_ENABLEOPENTELEMETRY` | `Monitoring.EnableOpenTelemetry` | Enable OpenTelemetry tracing and metrics. | `true` |
| `EnableAppInsights` | `MONITORING_ENABLEAPPINSIGHTS` | `Monitoring.EnableAppInsights` | Send telemetry to Azure Application Insights. | `true` |
| `AppInsightsConnectionString` | `MONITORING_APPINSIGHTSCONNECTIONSTRING` | `Monitoring.AppInsightsConnectionString` | Connection string for Azure Application Insights. | `"InstrumentationKey=...;IngestionEndpoint=...;ApplicationId=..."` |
| `EnableNpgsqlInstrumentation` | `MONITORING_ENABLENPGSQLINSTRUMENTATION` | `Monitoring.EnableNpgsqlInstrumentation` | Trace and monitor PostgreSQL interactions. | `true` |
| `EnableAspNetCoreInstrumentation` | `MONITORING_ENABLEASPNETCOREINSTRUMENTATION` | `Monitoring.EnableAspNetCoreInstrumentation` | Trace and monitor ASP.NET Core requests. Ignored if App Insights is enabled. | `true` |
| `EnableHttpClientInstrumentation` | `MONITORING_ENABLEHTTPCLIENTINSTRUMENTATION` | `Monitoring.EnableHttpClientInstrumentation` | Trace and monitor HTTP Client calls. Ignored if App Insights is enabled. | `true` |

---

## Exporters

| Setting Name | Environment Variable | appsettings.json Key | Description | Example Value |
|--------------|----------------------|------------------------|-------------|----------------|
| `EnableOtlpExporter` | `MONITORING_ENABLEOTLPEXPORTER` | `Monitoring.EnableOtlpExporter` | Enables the OpenTelemetry Protocol (OTLP) exporter. | `true` |
| `EnableConsoleExporter` | `MONITORING_ENABLECONSOLEEXPORTER` | `Monitoring.EnableConsoleExporter` | Enables export to console (for debugging). | `true` |
| `EnablePrometheusExporter` | `MONITORING_ENABLEPROMETHEUSEXPORTER` | `Monitoring.EnablePrometheusExporter` | Enables export in Prometheus format. | `true` |

---

## Filters

| Setting Name | Environment Variable | appsettings.json Key | Description | Example Value |
|--------------|----------------------|------------------------|-------------|----------------|
| `LogLevelConsole` | `MONITORING_LOGLEVELCONSOLE` | `Monitoring.LogLevelConsole` | Minimum log level for console output. | `"Information"` |
| `ActivitySourcesFilter` | `MONITORING_ACTIVITYSOURCESFILTER` | `Monitoring.ActivitySourcesFilter` | Comma-separated list of activity sources to include in tracing. | `"AiCoreApi.SemanticKernel.Agents.*"` |
| `MetricsFilter` | `MONITORING_METRICSFILTER` | `Monitoring.MetricsFilter` | Comma-separated list of metric names to include or exclude. | `"aicore.*"` |
